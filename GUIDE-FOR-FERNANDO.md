# How to use the placement test website

## What you need

Three things, which Gagan will send you:

1. **The link** to the test (it looks like `https://something.trycloudflare.com`)
2. **The access code** students type to start (for example `hola2026`)
3. **Your teacher password** for seeing the results

The link changes every time the website is restarted. If a student says the
link doesn't work, check with Gagan that you have the latest one.

## Before class

Send students the link and the access code. That's it. They don't need an
account, an app, or anything installed. It works on phones, tablets, and
laptops.

## What students see

1. **The instructions**, then three boxes: their name, their class, and the
   access code. They press **Empezar el test**.
2. **One question at a time.** They tap an answer and press **Siguiente**.
   If they don't know, they press **No lo sé, saltar** (it counts as wrong,
   just like leaving it blank on paper).
3. **The test ends by itself.** After every 20 questions, if a student got
   7 or more wrong, the test stops. Strong students go all the way to 120.
4. **Their level appears on screen** (A1, A2, B1, B2, C1, C2, or Pre-A1).

If a student closes the page by accident or their phone dies, they just open
the link again, type the same name and class, and continue where they left
off. Nothing is lost.

A student can only take the test once. If someone needs to redo it, see
"Letting a student retake" below.

## Seeing the results

1. Open the link and add `/teacher` at the end.
   Example: `https://something.trycloudflare.com/teacher`
2. A small login box appears. Type anything as the username (for example
   `profe`) and your teacher password.
3. You'll see a table with every student: name, class, whether they've
   finished, time taken, points, level, and their score in each level.

**To see one student's answers**, click their name. You'll see every question,
what they chose, the right answer, and a ✓ or ✗.

## Getting the results in Excel

On the results page there are two buttons at the top right:

- **Resultados CSV** — one line per student with name, class, points, and
  level. This is the one you'll usually want.
- **Respuestas CSV** — every single answer from every student, in case you
  want to see which questions were hardest.

Click one, and a file downloads. Open it in Excel.

## Letting a student retake the test

On the results page, find the student and click **Borrar** on their line.
Their result is deleted and they can start again.

## Good to know

- The website runs on Gagan's laptop. It only works while that laptop is on
  and connected. Agree with Gagan on when it should be running.
- Students can't see the correct answers, during or after the test.
- Only you can see the results. Keep the teacher password to yourself.
