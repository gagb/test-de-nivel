# Test de nivel — online placement test

An online version of the ProfeDeELE.es progressive Spanish placement test
(*Examen progresivo - Test de nivel v.1.3*). Students take it in a browser;
the teacher reads everyone's grades in a private console and exports them to
Excel.

## Architecture

Self-contained Flask app with a local SQLite database. No third-party
services.

- **Student page** (`index.html`, generated by `build.py`) — all 120
  questions, name and class fields. It carries **no answer key**, so students
  cannot read the answers from the page source.
- **Server** (`app.py`) — grades each submission against `test-data.json`,
  stores the result in `results.db`, and returns the student's level.
- **Teacher console** (`/teacher`, password protected) — table of all results
  with a one-click **CSV/Excel export**.

## Run locally

```bash
pip install -r requirements.txt
python build.py                    # regenerate index.html from test-data.json
TEACHER_PASSWORD=yourpassword python app.py
```

- Student test: <http://127.0.0.1:5000/>
- Teacher console: <http://127.0.0.1:5000/teacher> (any username, password =
  `TEACHER_PASSWORD`; defaults to `changeme` if unset).

To run the test for a class, host `app.py` somewhere the students can reach
(a small cloud host, or the teacher's laptop on the same network) and share
the URL.

## Test structure and scoring

- 120 multiple-choice questions, one correct answer each.
- 20 questions per level, in order: A1, A2, B1, B2, C1, C2.
- **Points** = total correct out of 120 (a blank answer counts as wrong).
- A level is *passed* with **6 or fewer** wrong answers out of its 20
  (`maxErrorsPerLevel` in `test-data.json`).
- **Level** = the highest level passed scanning A1 → C2; once a level is
  failed, later levels don't count. A student who fails A1 gets `-`.

## Files

| File | Purpose |
|------|---------|
| `test-data.json` | Source of truth: 120 questions, options, answer key, scoring rules. |
| `build.py` | Generates `index.html` from `test-data.json` (strips the answer key). |
| `index.html` | Generated student page. Do not edit by hand; edit the data and rebuild. |
| `app.py` | Flask server: grading, storage, teacher console, CSV export. |
| `requirements.txt` | Python dependencies (Flask). |

Note: question 115 has three options (a–c); all others have four.
